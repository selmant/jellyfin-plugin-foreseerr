Access

Use administrators only while you set Foreseerr up. Foreseerr's own user settings still apply: Enable New Jellyfin Sign-In in Foreseerr decides whether Jellyfin users it has not imported can open it. The first Jellyfin administrator to open Foreseerr becomes its owner, and Jellyfin administrators are Foreseerr admins.
