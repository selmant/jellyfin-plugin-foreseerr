Sixth alpha of **Foreseerr for Jellyfin**, bundling Foreseerr v0.14.0.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Changes

- Bundles Foreseerr v0.14.0. Simkl links through Simkl's AUTH V2 with Foreseerr's own Simkl app, so nothing needs to be registered on Simkl: turn on **Enable Simkl** in Settings → Integrations → Simkl. An install with its own Simkl Client ID keeps it and can switch to Foreseerr's app. Library sync downloads only what changed on Simkl.
- Also from v0.14.0: watch-ahead requests no longer monitor an episode again after it was unmonitored outside Foreseerr before it was downloaded, Simkl sliders show their names in Discover's edit mode, See More cards preview the titles after the row, and the Quick Connect dialog shows its large code again.
- Includes Foreseerr v0.13.4: completed watch-ahead episodes whose files were deleted are no longer searched again.
- Ships builds for Jellyfin 10.11 and 12. The plugin's numeric versions are `0.1.0.1060` and `0.1.0.1061`, respectively.

## Upgrade notes

- New Foreseerr database migrations since the v0.13.3 bundled with `0.1.0-alpha.5`: `AddWatchAheadMonitorTracking`, `AddSimklRefreshToken` and `AddSimklWatchedEpisodes`. Each user's Simkl library resyncs once.
- Back up Jellyfin's plugin configuration before updating. The plugin remains alpha with no promised compatibility or upgrade path between plugin versions.
