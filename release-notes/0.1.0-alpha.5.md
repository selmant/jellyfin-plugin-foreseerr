Fifth alpha of **Foreseerr for Jellyfin**, bundling Foreseerr v0.13.3.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Changes

- Bundles Foreseerr v0.13.3. Watch-ahead requests no longer monitor episodes again after their files were deleted, so a cleanup tool such as Maintainerr no longer sets off a delete and re-download loop.
- Includes Foreseerr v0.13.2: linking Simkl and saving a Simkl Client ID now show Simkl's reason when it refuses, and a wrong Client ID is rejected.
- Includes Foreseerr v0.13.1: every Discover source card shares one layout, Trakt gains Trending, Popular, and Anticipated, and public AniList lists open from an anilist.co link.
- Ships builds for Jellyfin 10.11 and 12. The plugin's numeric versions are `0.1.0.1050` and `0.1.0.1051`, respectively.

## Upgrade notes

- No new Foreseerr database migrations since the v0.13.0 bundled with `0.1.0-alpha.4`.
- Back up Jellyfin's plugin configuration before updating. The plugin remains alpha with no promised compatibility or upgrade path between plugin versions.
