Third alpha of **Foreseerr for Jellyfin**, bundling Foreseerr v0.11.1.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Changes

- Anime mapping packs are no longer downloaded on first run. Enable the ones you want under Foreseerr's **Settings → Mapping**; until then, Mapping and AniList settings show a warning, and some anime may not show up or be requestable. Installs that already have packs keep them.

## Fixes

- Installing or refreshing a mapping pack no longer makes Foreseerr stop answering for minutes, which Jellyfin reported as 504 Gateway Timeout on `/Foreseerr`.
- The calendar's **Discover titles** button opened the 404 page. An empty calendar now also says when no Sonarr or Radarr server is connected.
