**Foreseerr for Jellyfin 0.15.0-alpha.1**, bundling Foreseerr v0.15.0. The plugin version now follows the Foreseerr release it bundles (this is the release after `0.1.0-alpha.6`), and a new Foreseerr release publishes a matching plugin release automatically.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Changes

- The bundled Foreseerr server is now Foreseerr's Rust backend, the same server as its Docker image, instead of a Bun-compiled Node server. The plugin starts it, signs users in, and proxies it as before. The zip's `sidecar/` folder holds one binary per platform (`foreseerr-linux-x64`, `foreseerr-linux-arm64`, `foreseerr-windows-x64.exe`) and one shared copy of the web app (`dist/public/`), the API spec (`seerr-api.yml`), and `committag.json`.
- The plugin bundles the runtimes Foreseerr v0.15.0 publishes for the plugin, checked against the release's `SHA256SUMS`, instead of compiling Foreseerr itself.
- Foreseerr v0.15.0 also brings Sonarr 5 support, episode-order matching by TVDB id, a reworked Manual Import, and one database migration (`AddRequestMetadataLanguage`); see its release notes below.
- Ships builds for Jellyfin 10.11 and 12. The plugin's numeric versions are `0.15.0.1010` and `0.15.0.1011`, respectively, so `0.1.0-alpha.6` installs update to them.

## Upgrade notes

- The Linux server still needs glibc, so Alpine-based Jellyfin images cannot run it, and NixOS needs `programs.nix-ld.enable = true;`.
- Back up Jellyfin's plugin configuration before updating. The plugin remains alpha with no promised compatibility or upgrade path between plugin versions.
