Second alpha of **Foreseerr for Jellyfin**, bundling Foreseerr v0.11.0.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Fixes

- Better Trakt is now detected when it is installed as a drop-in for the official Trakt plugin (same `Trakt.dll` and plugin ID, named "Better Trakt"). Before, Foreseerr did not switch Trakt to Better Trakt on such servers. Existing installs pick it up on the next Jellyfin restart, unless a Direct Trakt app is configured.

## Notes

- The plugin now lives in its own repository. Add `https://selmant.github.io/jellyfin-plugin-foreseerr/manifest.json` under Dashboard → Plugins → Repositories if you installed from an older URL.
- On NixOS, the bundled Foreseerr server needs `programs.nix-ld.enable = true;`. Alpine-based Jellyfin images cannot run it.
